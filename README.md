# Money Tracker Web - Quick Start

## Menjalankan Aplikasi

1. Buka terminal/command prompt
2. Masuk ke folder project:
   ```
   cd "D:\Bahan PS\Pribadi\money-tracker-web"
   ```

3. Jalankan development server:
   ```
   npm run dev
   ```

4. Buka browser: http://localhost:3000

5. Stop server: Tekan `Ctrl + C` di terminal

## Database GUI (Optional)

Untuk melihat data di database:
```
npx prisma studio
```
Akan buka di: http://localhost:5555

## File Penting

- Database: `prisma/dev.db`
- Backup database: Copy file `dev.db`
- Dokumentasi lengkap: Lihat `SETUP_GUIDE.md`
